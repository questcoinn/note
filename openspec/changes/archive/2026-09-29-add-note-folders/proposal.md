## Why

노트가 늘어나도 지금은 최근 수정 순으로 쌓인 한 목록에서만 찾을 수 있다. 목업 시절 사이드바에 보이던 폴더는 지난 변경(`add-note-create-delete`)에서 실제 데이터가 없다는 이유로 걷어냈고, 저장 형식에는 `folderId` 자리만 남아 있다. 이제 사용자가 직접 폴더를 만들고 노트를 나눠 담아, 사이드바에서 폴더를 골라 그 노트만 볼 수 있게 한다.

## What Changes

- 사이드바에 "폴더 없음" 항목과 "폴더" 그룹을 추가한다. "전체 노트", "폴더 없음", 각 폴더 항목은 실제 노트 수를 보여주고, 누르면 가운데 노트 목록이 그 범위로 좁혀지며 목록 제목도 범위 이름으로 바뀐다. 폴더는 가나다순이다.
- 폴더 만들기(그룹 제목 옆 `+` 버튼)와 이름 바꾸기는 이름 입력 다이얼로그로 한다. 빈 이름, 이미 있는 이름, "전체 노트"·"폴더 없음"은 받지 않고 이유를 문구로 보여준다.
- 각 폴더 항목의 메뉴 버튼(항상 보임)에서 "이름 바꾸기"와 "삭제"를 고른다. 삭제는 확인 다이얼로그를 거치며, 안에 있던 노트는 지우지 않고 "폴더 없음"으로 옮긴다. 보고 있던 폴더를 지우면 목록이 "전체 노트"로 바뀐다.
- 에디터 상단에 노트의 폴더를 고르는 선택 컨트롤을 둔다. 바꾸면 바로 저장하고 수정 시각은 바꾸지 않는다.
- 폴더를 보는 중에 만든 새 노트는 그 폴더에 들어간다. "전체 노트"나 "폴더 없음"에서 만든 새 노트는 폴더가 없다.
- 열려 있는 노트는 사용자가 닫기 전까지 닫지 않는다. 좁혀진 목록에서 노트의 폴더를 바꾸면 그 카드만 목록에서 빠지고 에디터는 그대로다. 사이드바에서 다른 범위를 골라도 에디터에 열린 노트는 그대로다.
- 범위별 빈 상태를 추가한다: 빈 폴더(그 폴더에 새 노트를 만드는 버튼과 함께), 폴더 없음 노트가 없을 때.
- 존재하지 않는 폴더를 가리키는 저장된 노트(예전 목업이 남긴 `work` 등)는 "폴더 없음"으로 보여준다. 저장본의 값은 사용자가 그 노트의 폴더를 바꿀 때까지 고치지 않는다.
- **BREAKING**(동작): 사이드바 항목이 이제 실제로 동작한다. "사이드바 항목은 동작하지 않음" 동작과 "사이드바에는 새 노트와 전체 노트만" 제약을 없앤다.

범위 제외: 하위 폴더, 드래그 앤 드롭으로 옮기기, 폴더 순서 바꾸기, 태그, 보던 범위를 새로고침 뒤에도 기억하기, 폴더 삭제 되돌리기, 여러 노트 한꺼번에 옮기기, 검색 필터링.

## Capabilities

### New Capabilities
- `note-folders`: 폴더 데이터와 영속 저장, 사이드바 폴더 탐색과 목록 범위, 폴더 만들기·이름 바꾸기·삭제, 노트의 폴더 지정과 바꾸기, 범위별 빈 상태

### Modified Capabilities
- `note-ui-skeleton`: 3단 화면의 사이드바 구성 제약을 폴더 항목 포함으로 변경. "사이드바 항목은 동작하지 않음" 시나리오 제거. 새 노트가 보던 폴더에 들어가도록 변경. 노트 없음 빈 상태와 노트 미선택 빈 상태의 "새 노트" 버튼 규칙을 범위별 빈 상태에 맞게 변경. 저장소 쓰기 범위에 폴더 저장 포함
- `note-persistence`: 새 노트의 첫 기록 레코드가 만든 범위의 폴더를 갖도록 변경. 손상되거나 알 수 없는 저장 데이터 규칙을 폴더 레코드까지 넓힘

## Impact

- 코드: `src/lib/persistence/store.ts`(폴더 레코드 형식과 저장소 인터페이스), `src/lib/persistence/local-storage-store.ts`(폴더 키), `src/lib/persistence/autosave.svelte.ts`(끝날 때까지 기다릴 수 있는 즉시 저장), `src/lib/notes.svelte.ts`(`folderId` 변경 가능, 폴더 바꾸기), 새 폴더 상태 모듈, `src/lib/ui-state.svelte.ts`(목록 범위), `src/main.ts`(폴더 불러오기), `src/lib/layout/Sidebar.svelte`, `src/lib/layout/NoteList.svelte`, `src/lib/layout/EditorPane.svelte`, `src/lib/components/SidebarNavItem.svelte`(누르기, 메뉴 버튼), 새 폴더 이름 다이얼로그·메뉴 컴포넌트
- 의존성: 추가 없음
- 저장 데이터: 노트 레코드 형식(v1)은 바꾸지 않는다. 폴더는 `folder:v1:<id>` 키로 따로 저장한다. 폴더를 지우면 안에 있던 노트 레코드를 `folderId: ''`로 다시 기록한다
- 디자인 계약: DESIGN.md에 없는 컴포넌트(폴더 메뉴, 에디터 폴더 선택, 이름 입력 다이얼로그)를 구현 전에 oh-my-design 절차로 계약에 추가해야 한다. `sidebar-nav-item`의 folder 변형을 처음으로 실제 사용한다
