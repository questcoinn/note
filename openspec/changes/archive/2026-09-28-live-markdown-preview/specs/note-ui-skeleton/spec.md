## ADDED Requirements

### Requirement: 노트 선택과 원문 편집
노트 카드를 활성화하면 해당 카드가 selected 상태로 표시되고 에디터 영역에 그 노트의 마크다운 원문과 원문에서 렌더링된 미리보기가 나란히 표시되어야 한다(SHALL). 원문 영역은 모노스페이스 글꼴을 사용해야 한다(MUST). 원문을 수정하면 미리보기와 해당 노트 카드의 제목·미리보기 문장이 즉시 갱신되어야 하며(SHALL), 렌더링과 파생 규칙은 `markdown-preview` capability를 따른다. 원문 수정은 목록의 노트 순서, 수정 시각 문구, 폴더/태그 개수를 바꾸지 않아야 한다(MUST NOT change).

#### Scenario: 카드 클릭으로 노트 열기
- **WHEN** 사용자가 노트 목록에서 카드 하나를 클릭하거나 키보드로 포커스 후 Enter를 누른다
- **THEN** 그 카드만 selected 배경으로 표시된다
- **AND** 에디터 영역 왼쪽에 해당 노트의 마크다운 원문이, 오른쪽에 렌더링된 미리보기가 표시된다
- **AND** 에디터 상단에 저장 상태 표시, 서식 도구 버튼 6종(굵게, 기울임, 제목, 링크, 목록, 코드), 삭제 버튼이 보인다

#### Scenario: 원문을 고치면 미리보기와 카드가 바뀜
- **WHEN** 사용자가 원문 영역에 글자를 입력한다
- **THEN** 미리보기와 해당 노트 카드의 제목·미리보기 문장이 입력 내용을 반영한다
- **AND** 목록의 노트 순서, 카드의 수정 시각 문구, 사이드바의 개수는 그대로다

#### Scenario: 서식 도구와 사이드바 항목은 동작하지 않음
- **WHEN** 사용자가 서식 도구 버튼, 폴더/태그 항목, 태그 칩, "새 노트" 버튼을 누른다
- **THEN** 원문, 목록 내용, 선택 노트는 바뀌지 않는다 (hover/focus/active 시각 상태만 나타난다)

## MODIFIED Requirements

### Requirement: 저장 상태 표시 3종
에디터의 저장 상태 표시는 저장됨, 저장 중, 저장 안 됨 세 변형을 아이콘과 문구를 함께 사용해 표시해야 한다(SHALL). 이 세션에서 원문을 한 번도 고치지 않은 노트는 저장됨, 원문을 고친 노트는 저장 안 됨으로 표시해야 한다(SHALL). 편집 내용은 영속 저장되지 않기 때문이다. URL 쿼리로 강제한 변형은 이 규칙보다 우선한다. 이 표시는 클릭할 수 없어야 한다(MUST NOT be interactive).

#### Scenario: 기본 저장 상태
- **WHEN** 노트가 선택되어 있고, 이 세션에서 그 노트의 원문을 고친 적이 없으며, `save` 쿼리가 없다
- **THEN** 아이콘과 "저장됨" 문구가 success 색으로 보인다

#### Scenario: 편집하면 저장 안 됨
- **WHEN** `save` 쿼리 없이 사용자가 노트 A의 원문에 글자를 입력한다
- **THEN** 아이콘과 "저장 안 됨" 문구가 danger 색으로 보인다
- **WHEN** 사용자가 편집하지 않은 노트 B를 연다
- **THEN** "저장됨"이 보인다
- **WHEN** 사용자가 다시 노트 A를 연다
- **THEN** "저장 안 됨"이 보인다

#### Scenario: 강제 변형
- **WHEN** URL에 `?save=saving` 또는 `?save=unsaved`가 있다
- **THEN** 편집 여부와 관계없이 각각 아이콘과 "저장 중"(muted 색), 아이콘과 "저장 안 됨"(danger 색)이 보인다

## REMOVED Requirements

### Requirement: 노트 선택은 표시만 바꾼다
**Reason**: 원문 편집이 미리보기와 목록 카드에 반영되도록 바뀌어, "원문을 수정해도 미리보기·목록이 바뀌지 않는다"는 뼈대 단계 규칙이 더 이상 성립하지 않는다.
**Migration**: 같은 파일의 ADDED 요구사항 "노트 선택과 원문 편집"으로 대체한다. 카드 선택, 2단 표시, 모노스페이스 원문, 서식 도구·사이드바 항목 비동작 시나리오는 그대로 옮겨 왔다.
