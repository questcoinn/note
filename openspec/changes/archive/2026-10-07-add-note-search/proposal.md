## Why

노트 목록에는 검색 입력이 있지만 뼈대 단계 그대로라 글자를 넣어도 목록이 바뀌지 않는다. 검색 결과 없음 상태도 `?search=empty` URL 쿼리로만 볼 수 있다. 노트가 쌓이면 폴더와 태그만으로는 "그 말을 적어 둔 노트"를 다시 찾기 어렵다. DESIGN.md가 주요 작업으로 꼽은 "검색으로 특정 노트 즉시 찾기"를 노트 내용 검색으로 채운다.

## What Changes

- 검색 입력에 글자를 넣으면 지금 보고 있는 범위(전체 노트, 폴더 없음, 폴더, `#태그`)의 노트 가운데 내용이 일치하는 노트만 목록에 남는다. 범위는 바뀌지 않는다.
- 검색 대상은 미리보기에 렌더링되어 보이는 글자다. 제목, 문단, 목록, 인용, 표 셀, 코드, 링크 텍스트, 이미지 대체 텍스트가 들어가고, 마크다운 기호와 링크 주소는 빠진다. 내용이 없는 노트의 "제목 없음"은 내용이 아니라서 걸리지 않는다.
- 일치 규칙: 검색어를 공백으로 나눈 단어가 모두 들어 있어야 한다. 단어는 부분 일치로 찾고, 대소문자는 구분하지 않으며, 유니코드 정규화(NFC) 차이도 무시한다. 한글 입력기로 조합하는 중에도 바로 필터링한다.
- 검색 중인 노트 카드는 제목의 일치한 단어를 하이라이트하고, 본문에서 처음 일치한 줄의 일치 부분 주변을 스니펫 자리에 보여준다. 본문에 일치가 없으면 원래 스니펫을 쓴다.
- 결과가 없으면 "일치하는 노트가 없어요" 빈 상태를 보여준다. 범위 자체가 비어 있으면 기존 범위별 빈 상태가 먼저다. 지금 범위 밖(전체 노트)에는 일치하는 노트가 있으면 그 개수와 "전체 노트에서 보기" 버튼을 함께 보여준다.
- 검색 결과에 없는 노트가 열려 있어도 에디터에서 닫지 않는다. 검색어는 범위를 바꾸거나 새 노트를 만들어도 남고, 새로고침하면 지워진다.
- `Cmd/Ctrl+K`로 검색 입력에 포커스하고, 검색 입력 안에서 `Esc`를 누르면 검색어를 지운다.
- **BREAKING**(개발용): `?search=empty` 강제 상태를 없앤다. 검색 입력은 이제 목록을 필터링한다.

범위 제외: 태그 이름·폴더 이름 검색, 에디터 원문이나 미리보기 안의 검색어 하이라이트와 그 위치로 스크롤, 초성 검색, 오타 허용, 검색 결과 관련도 순 정렬, 검색어를 새로고침 뒤에도 기억하기, 검색 기록.

## Capabilities

### New Capabilities
- `note-search`: 내용 검색의 대상 텍스트와 일치 규칙, 범위와의 관계, 결과 카드의 하이라이트와 발췌, 검색 결과 없음 빈 상태와 범위 밖 안내, 열린 노트와 검색어 유지, 검색 단축키

### Modified Capabilities
- `note-ui-skeleton`: "검색 결과 없음 상태"(URL 강제 표시, 입력해도 필터링 안 함)를 제거하고 `note-search`에 넘긴다. "노트 없음 빈 상태"에서 `?search=empty` 우선 규칙을 뺀다
- `note-folders`: "범위별 빈 상태"에서 `?search=empty` 우선 규칙을 뺀다
- `note-tags`: "태그 범위의 빈 상태"에서 `?search=empty` 우선 규칙을 뺀다

## Impact

- 코드
  - `src/lib/markdown/render.ts`: 검색용 평문 줄 파생(표 셀 포함). 제목·스니펫 파생 규칙은 그대로
  - `src/lib/notes.svelte.ts`: `NoteDoc`에 검색용 평문 파생값
  - 새 검색 모듈: 검색어 정리, 일치 판정, 발췌와 하이라이트 구간 계산(순수 함수)
  - `src/lib/ui-state.svelte.ts`: `ui.searchQuery`, `readForced()`·`forced`·`FORCED_SEARCH_QUERY` 제거, `listEmptyShowsNewNote` 정리
  - `src/lib/layout/NoteList.svelte`: 필터링, 빈 상태 분기, "전체 노트에서 보기"
  - `src/lib/components/NoteCard.svelte`: 하이라이트된 제목과 발췌
  - `src/lib/components/SearchInput.svelte`: 뼈대 주석 제거, `Esc`로 지우기
  - `Cmd/Ctrl+K` 전역 단축키
- 의존성: 추가 없음
- 저장 데이터: 바뀌지 않는다. 검색어는 저장하지 않는다
- 디자인 계약: 구현 전에 oh-my-design 절차로 DESIGN.md를 고친다
  - `note-card`에 검색 일치 발췌와 하이라이트(weak-background/weak-foreground, selected 카드에서는 canvas 배경) 추가
  - `search-input`의 no-results 상태와 범위 밖 안내 문구, `Esc`로 지우기 명시
