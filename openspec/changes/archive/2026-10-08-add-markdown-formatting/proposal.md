## Why

에디터의 태그 줄과 원문 사이에 서식 도구 버튼 6개(굵게, 기울임, 제목, 링크, 목록, 코드)가 뼈대 단계부터 보이지만, 눌러도 아무 일도 일어나지 않는다. 사용자는 보이는 도구가 동작한다고 기대한다. 마크다운 기호를 외우지 않아도 서식을 넣고 뺄 수 있게, 버튼을 실제로 동작하게 만든다.

## What Changes

- 서식 도구 버튼 6개가 원문의 선택 영역이나 커서 위치에 마크다운 서식을 넣거나 뺀다.
  - 굵게(`**`), 기울임(`*`), 코드(`` ` ``)는 선택한 글을 감싼다. 이미 감싸져 있으면 푼다. 여러 줄에 걸친 코드는 코드 블록(```` ``` ````)으로 감싼다.
  - 제목(`## `)과 목록(`- `)은 선택 영역이 걸친 줄 앞에 붙인다. 모든 줄에 이미 붙어 있으면 뗀다.
  - 링크는 다이얼로그 없이 `[선택한 글](url)`을 넣고 `url`을 선택해 바로 덮어쓰게 한다. 선택한 글이 주소처럼 생겼으면 `[](주소)`를 넣고 커서를 대괄호 안에 둔다.
- 서식 적용은 직접 입력한 것과 똑같이 미리보기, 카드, 수정 시각, 자동 저장에 반영된다. 되돌리기(Cmd/Ctrl+Z) 한 번에 서식 적용 하나가 통째로 취소된다.
- 원문에서 Cmd/Ctrl+B는 굵게, Cmd/Ctrl+I는 기울임을 적용한다. Cmd/Ctrl+K는 검색이 쓰고 있어 링크 단축키는 두지 않는다.
- 서식 도구는 `role="toolbar"`에 맞게 Tab 한 번으로 들어가고 화살표 키로 버튼 사이를 옮긴다.
- 편집/미리보기 탭을 쓰는 1024px 미만 폭에서는, 미리보기 탭을 보는 동안 서식 도구를 숨긴다.

범위 제외: 커서가 있는 곳의 서식에 따라 버튼을 눌린 모양으로 바꾸는 표시(`aria-pressed`), 링크 주소 입력 다이얼로그, 제목 단계(`#`~`###`) 돌리기, 번호 목록과 체크박스 목록 버튼, 링크 단축키, 서식 함수 단위 테스트 러너 도입.

## Capabilities

### New Capabilities
- `markdown-formatting`: 서식 도구 6종의 넣기·빼기 규칙, 적용 뒤 선택 영역, 되돌리기, 단축키, 툴바 키보드 탐색, 좁은 폭 미리보기 탭에서 툴바 숨기기

### Modified Capabilities
- `note-ui-skeleton`: "노트 선택과 원문 편집"을 "노트 열기와 원문 편집"으로 다시 정의한다(OpenSpec은 MODIFIED에서 시나리오를 뺄 수 없어 REMOVED와 ADDED로 바꾼다). "서식 도구와 사이드바 항목은 동작하지 않음" 시나리오는 사이드바 부분만 남기고, 서식 도구 동작은 `markdown-formatting`을 따른다고 적는다. 서식 도구 위치도 실제 화면대로 "태그 줄과 원문 사이"로 바로잡는다

## Impact

- 코드
  - 새 모듈 `src/lib/markdown/format.ts`: 서식별 순수 함수. 원문과 선택 영역을 받아 바꿀 범위와 새 선택 영역을 돌려준다
  - 새 모듈 `src/lib/markdown/apply-edit.ts`: 그 결과를 textarea에 적용하는 유일한 DOM 접점. `document.execCommand('insertText')`를 여기에만 둔다
  - `src/lib/components/MarkdownToolbarButton.svelte`: 누르기 동작, roving tabindex
  - `src/lib/layout/EditorPane.svelte`: 툴바 화살표 키 이동, 원문 단축키, 미리보기 탭에서 툴바 숨기기
- 의존성: 추가 없음
- 브라우저 API: 되돌리기 기록을 지키려고 deprecated 표시가 있는 `document.execCommand('insertText')`를 쓴다. 근거와 교체 경로는 design.md에 적는다
- 저장 데이터: 바뀌지 않는다
- 디자인 계약: 구현 전에 oh-my-design 절차로 DESIGN.md의 `markdown-toolbar-button`을 고친다. `active`는 누르는 동안의 상태이고, 커서 위치에 따른 눌린 상태가 아님을 적는다. 좁은 폭 미리보기 탭에서 툴바를 숨기는 레이아웃 규칙도 넣는다
