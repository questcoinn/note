## Purpose

에디터의 서식 도구 버튼과 단축키로 원문의 선택 영역이나 커서 위치에 마크다운 서식을 넣고 뺀다. 마크다운 기호를 외우지 않아도 굵게, 기울임, 제목, 링크, 목록, 코드를 쓸 수 있게 하고, 적용한 서식은 직접 입력한 것과 똑같이 저장되고 되돌릴 수 있게 한다.

## ADDED Requirements

### Requirement: 서식 적용은 원문 수정이다
서식 도구 버튼을 누르거나 서식 단축키를 쓰면 열린 노트의 원문을 이 capability의 규칙대로 바꿔야 한다(SHALL). 이 변경은 사용자가 직접 입력한 원문 수정과 똑같이 미리보기, 카드의 제목·미리보기 문장, 수정 시각, 자동 저장에 반영되어야 한다(SHALL). 서식 적용 하나는 되돌리기(`Cmd+Z` 또는 `Ctrl+Z`) 한 번으로 통째로 취소되어야 하고(SHALL), 그 전에 입력한 내용의 되돌리기 기록을 지우지 않아야 한다(MUST NOT). 적용한 뒤에는 포커스가 원문 영역에 있고, 각 규칙이 정한 범위가 선택되어 있거나 커서가 그 자리에 있어야 한다(SHALL). 선택 영역은 원문 영역에 마지막으로 있던 선택 영역이다. 포커스가 서식 도구 버튼으로 옮겨 가도 그 선택 영역을 쓴다.

#### Scenario: 버튼으로 굵게 적용 후 저장
- **WHEN** 사용자가 원문에서 `회의`를 선택하고 "굵게" 버튼을 누른다
- **THEN** 원문의 그 자리가 `**회의**`가 되고 미리보기에 "회의"가 굵게 보인다
- **AND** 노트 카드의 수정 시각 문구가 "방금 전"이 되고 저장 상태가 "저장 중"을 거쳐 "저장됨"이 된다
- **AND** 포커스는 원문 영역에 있고 `회의`가 선택되어 있다

#### Scenario: 되돌리기 한 번
- **WHEN** 사용자가 원문에 `안녕`을 입력한 뒤 `안녕`을 선택해 "굵게"를 누르고 `Cmd+Z`(macOS) 또는 `Ctrl+Z`를 한 번 누른다
- **THEN** 원문이 `안녕`으로 돌아간다
- **WHEN** 사용자가 되돌리기를 더 누른다
- **THEN** `안녕`을 입력하기 전의 원문으로 돌아간다

### Requirement: 인라인 서식 감싸기와 풀기
굵게(`**`), 기울임(`*`), 코드(`` ` ``)는 선택한 글자를 앞뒤 기호로 감싸야 한다(SHALL). 선택 영역 맨 앞과 맨 뒤의 공백은 감싸지 않고 기호 밖에 남겨야 한다(MUST). 선택한 글자가 이미 그 서식의 기호로 감싸져 있으면(기호가 선택 영역 바로 안쪽 양 끝에 있거나 바로 바깥 양쪽에 있으면) 기호를 지워 풀어야 한다(SHALL). 감싸거나 푼 뒤에는 기호를 뺀 원래 글자가 선택되어 있어야 한다(SHALL).

- 선택 영역이 없으면 커서 자리에 기호 한 쌍을 넣고 커서를 그 사이에 두어야 한다(SHALL). 커서가 빈 기호 쌍(`**|**` 등) 사이에 있으면 그 쌍을 지워야 한다(SHALL).
- 굵게와 기울임은 별개로 판정한다. `*`가 2개 또는 3개 붙어 있으면 굵게로 감싸진 것이고, 1개 또는 3개 붙어 있으면 기울임으로 감싸진 것이다.
- 선택 영역이 여러 줄에 걸치면 굵게와 기울임은 빈 줄이 아닌 줄마다 따로 감싸야 한다(SHALL). 그 줄이 모두 이미 감싸져 있으면 모두 풀어야 한다(SHALL).
- 코드는 선택 영역이 한 줄 안이면 인라인 코드로 감싸야 한다(SHALL). 선택한 글자에 `` ` ``가 있으면 ` `` `와 안쪽 공백 한 칸으로 감싸야 한다(SHALL). 선택 영역이 여러 줄에 걸치면 걸친 줄 전체의 앞뒤에 ```` ``` ```` 줄을 넣어 코드 블록으로 감싸야 한다(SHALL). 걸친 줄의 바로 앞 줄과 바로 뒷 줄이 ```` ``` ````이면 그 두 줄을 지워 풀어야 한다(SHALL).

#### Scenario: 감싸고 다시 풀기
- **WHEN** 사용자가 `회의 자료`를 선택하고 "굵게"를 누른다
- **THEN** 원문이 `**회의 자료**`가 되고 `회의 자료`가 선택되어 있다
- **WHEN** 사용자가 "굵게"를 한 번 더 누른다
- **THEN** 원문이 `회의 자료`로 돌아가고 `회의 자료`가 선택되어 있다

#### Scenario: 앞뒤 공백은 감싸지 않음
- **WHEN** 사용자가 `오늘 회의 끝`에서 ` 회의 `(앞뒤 공백 포함)를 선택하고 "기울임"을 누른다
- **THEN** 원문이 `오늘 *회의* 끝`이 된다

#### Scenario: 선택 없이 누르기
- **WHEN** 커서가 줄 끝에 있을 때 사용자가 "굵게"를 누른다
- **THEN** 커서 자리에 `****`가 들어가고 커서가 가운데에 있다
- **WHEN** 사용자가 바로 "굵게"를 한 번 더 누른다
- **THEN** `****`가 지워진다

#### Scenario: 굵게 위에 기울임
- **WHEN** 원문 `**중요**`에서 사용자가 `중요`를 선택하고 "기울임"을 누른다
- **THEN** 원문이 `***중요***`가 된다
- **WHEN** 사용자가 "굵게"를 누른다
- **THEN** 원문이 `*중요*`가 된다

#### Scenario: 여러 줄 굵게
- **WHEN** 사용자가 `첫째`, 빈 줄, `둘째` 세 줄을 걸쳐 선택하고 "굵게"를 누른다
- **THEN** 원문이 `**첫째**`, 빈 줄, `**둘째**`가 된다

#### Scenario: 백틱이 든 인라인 코드
- **WHEN** 사용자가 ``a`b``를 선택하고 "코드"를 누른다
- **THEN** 원문이 ``` `` a`b `` ```가 된다

#### Scenario: 여러 줄 코드 블록
- **WHEN** 사용자가 `const a = 1`과 `const b = 2` 두 줄을 걸쳐 선택하고 "코드"를 누른다
- **THEN** 두 줄 앞에 ```` ``` ```` 줄이, 뒤에 ```` ``` ```` 줄이 생기고 미리보기에 코드 블록이 보인다
- **WHEN** 사용자가 같은 두 줄을 선택한 채 "코드"를 한 번 더 누른다
- **THEN** 앞뒤 ```` ``` ```` 줄이 지워진다

### Requirement: 줄 서식 붙이기와 떼기
제목과 목록은 선택 영역이 걸친 줄(선택 영역이 없으면 커서가 있는 줄)에 적용해야 한다(SHALL). 빈 줄은 건너뛰되, 걸친 줄이 모두 빈 줄이면 그 줄에 적용해야 한다(SHALL). 적용한 뒤에도 원래 선택했던 글자가 그대로 선택되어 있거나 커서가 같은 글자 옆에 있어야 한다(SHALL).

- 제목: 걸친 줄이 모두 `## `로 시작하면 `## `를 떼야 한다(SHALL). 그렇지 않으면 각 줄을 `## `로 시작하게 해야 하며, 다른 단계의 제목 기호(`#`~`######`와 공백)가 있으면 `## `로 바꿔야 한다(SHALL).
- 목록: 줄 앞의 들여쓰기 뒤에 `- `, `* `, `+ `가 있으면 목록 줄이다. 체크박스 목록(`- [ ] `, `- [x] `)도 목록 줄이다. 걸친 줄이 모두 목록 줄이면 목록 기호를 떼야 하며, 체크박스 목록은 `[ ] ` 또는 `[x] `까지 함께 떼야 한다(SHALL). 그렇지 않으면 목록 줄이 아닌 줄의 들여쓰기 뒤에 `- `를 붙여야 한다(SHALL). 번호 목록 기호(`1. `, `1) ` 등)는 `- `로 바꿔야 한다(SHALL).

#### Scenario: 제목 켜고 끄기
- **WHEN** 커서가 `회의록` 줄에 있을 때 사용자가 "제목"을 누른다
- **THEN** 그 줄이 `## 회의록`이 되고 미리보기에 제목으로 보인다
- **WHEN** 사용자가 "제목"을 한 번 더 누른다
- **THEN** 그 줄이 `회의록`으로 돌아간다

#### Scenario: 다른 단계 제목을 바꾸기
- **WHEN** 커서가 `### 안건` 줄에 있을 때 사용자가 "제목"을 누른다
- **THEN** 그 줄이 `## 안건`이 된다

#### Scenario: 여러 줄 목록 켜고 끄기
- **WHEN** 사용자가 `사과`, 빈 줄, `배`를 걸쳐 선택하고 "목록"을 누른다
- **THEN** 원문이 `- 사과`, 빈 줄, `- 배`가 된다
- **WHEN** 사용자가 "목록"을 한 번 더 누른다
- **THEN** 원문이 `사과`, 빈 줄, `배`로 돌아간다

#### Scenario: 일부만 목록인 줄
- **WHEN** 사용자가 `- 사과`와 `1. 배` 두 줄을 걸쳐 선택하고 "목록"을 누른다
- **THEN** 원문이 `- 사과`와 `- 배`가 된다

#### Scenario: 들여쓴 체크박스 목록 떼기
- **WHEN** 커서가 `  - [ ] 할 일` 줄에 있을 때 사용자가 "목록"을 누른다
- **THEN** 그 줄이 `  할 일`이 된다

### Requirement: 링크 넣기
"링크"는 주소를 묻는 창 없이 원문에 링크 문법을 넣어야 한다(SHALL). 이미 있는 링크를 푸는 동작은 없다.

- 선택한 글자(앞뒤 공백 제외)가 `http://` 또는 `https://`로 시작하고 공백이 없으면 `[](선택한 주소)`를 넣고 커서를 `[]` 안에 두어야 한다(SHALL).
- 그 밖에 선택한 글자가 있으면 `[선택한 글자](url)`을 넣고 `url`을 선택해 두어야 한다(SHALL).
- 선택 영역이 없으면 커서 자리에 `[](url)`을 넣고 커서를 `[]` 안에 두어야 한다(SHALL).

#### Scenario: 글자를 링크로
- **WHEN** 사용자가 `회의록`을 선택하고 "링크"를 누른다
- **THEN** 원문이 `[회의록](url)`이 되고 `url`이 선택되어 있다
- **WHEN** 사용자가 `https://example.com`을 입력한다
- **THEN** 원문이 `[회의록](https://example.com)`이 되고 미리보기에 "회의록" 링크가 보인다

#### Scenario: 주소를 링크로
- **WHEN** 사용자가 `https://example.com`을 선택하고 "링크"를 누른다
- **THEN** 원문이 `[](https://example.com)`이 되고 커서가 `[]` 안에 있다

### Requirement: 서식 단축키
원문 영역에 포커스가 있을 때 `Cmd+B`(macOS) 또는 `Ctrl+B`는 굵게, `Cmd+I` 또는 `Ctrl+I`는 기울임을 적용해야 하며(SHALL), 브라우저의 기본 동작은 일어나지 않아야 한다(MUST NOT). `Shift`나 `Alt`를 함께 누른 경우와 한국어 입력기 조합 중인 경우에는 적용하지 않아야 한다(MUST NOT). 원문 밖에서 누른 이 키는 서식을 적용하지 않는다. 다른 서식 도구에는 단축키가 없다.

#### Scenario: 단축키로 굵게
- **WHEN** 사용자가 원문에서 `회의`를 선택하고 `Cmd+B` 또는 `Ctrl+B`를 누른다
- **THEN** 원문이 `**회의**`가 되고 브라우저의 북마크 등 기본 동작은 일어나지 않는다

#### Scenario: 원문 밖에서는 적용 안 함
- **WHEN** 포커스가 태그 입력창에 있을 때 사용자가 `Cmd+B` 또는 `Ctrl+B`를 누른다
- **THEN** 원문은 바뀌지 않는다

### Requirement: 서식 도구 키보드 탐색
서식 도구는 Tab 순서에서 한 자리만 차지해야 한다(SHALL). 처음에는 "굵게" 버튼이 그 자리이고, 이후에는 마지막으로 포커스가 있던 버튼이 그 자리다. 서식 도구 안에서 오른쪽·왼쪽 화살표 키는 다음·이전 버튼으로 포커스를 옮기고 양 끝에서는 반대쪽 끝으로 넘어가야 하며(SHALL), `Home`과 `End`는 첫 버튼과 마지막 버튼으로 옮겨야 한다(SHALL). `Enter`나 `Space`로 버튼을 누르면 마우스로 누른 것과 같이 서식을 적용하고 포커스를 원문으로 옮겨야 한다(SHALL).

#### Scenario: 화살표로 버튼 옮기기
- **WHEN** 사용자가 태그 입력창에서 Tab을 누른다
- **THEN** "굵게" 버튼에 포커스 링이 보인다
- **WHEN** 사용자가 왼쪽 화살표 키를 누른다
- **THEN** "코드" 버튼으로 포커스가 옮겨 간다
- **WHEN** 사용자가 Tab을 누른다
- **THEN** 포커스가 서식 도구 다음 요소로 간다

### Requirement: 미리보기 탭에서 서식 도구 숨기기
편집/미리보기 탭을 쓰는 1024px 미만 폭에서 "미리보기" 탭이 선택되어 있으면 서식 도구가 보이지 않아야 한다(SHALL). "편집" 탭이 선택되어 있거나 1024px 이상 폭에서는 서식 도구가 보여야 한다(SHALL).

#### Scenario: 좁은 폭 탭 전환
- **WHEN** 사용자가 375px 폭에서 노트를 열고 "미리보기" 탭을 누른다
- **THEN** 서식 도구가 보이지 않는다
- **WHEN** 사용자가 "편집" 탭을 누른다
- **THEN** 서식 도구가 다시 보인다
