## ADDED Requirements

### Requirement: 노트 열기와 원문 편집
노트 카드를 활성화하면 해당 카드가 selected 상태로 표시되고 에디터 영역에 그 노트의 마크다운 원문과 원문에서 렌더링된 미리보기가 나란히 표시되어야 한다(SHALL). 원문 영역은 모노스페이스 글꼴을 사용해야 한다(MUST). 원문을 수정하면 미리보기와 해당 노트 카드의 제목·미리보기 문장이 즉시 갱신되어야 하며(SHALL), 렌더링과 파생 규칙은 `markdown-preview` capability를 따른다. 원문을 수정하면 그 노트의 수정 시각이 수정한 시각으로 바뀌고 카드의 수정 시각 문구도 그에 맞게 갱신되어야 한다(SHALL). 원문 수정은 사이드바의 어떤 노트 개수도 바꾸지 않아야 한다(MUST NOT change). 서식 도구로 원문을 바꾸는 것도 원문 수정이며, 서식 도구의 동작은 `markdown-formatting` capability를 따른다.

#### Scenario: 카드 클릭으로 노트 열기
- **WHEN** 사용자가 노트 목록에서 카드 하나를 클릭하거나 키보드로 포커스 후 Enter를 누른다
- **THEN** 그 카드만 selected 배경으로 표시된다
- **AND** 에디터 영역 왼쪽에 해당 노트의 마크다운 원문이, 오른쪽에 렌더링된 미리보기가 표시된다
- **AND** 에디터 상단에 폴더 선택, 저장 상태 표시, 삭제 버튼이 보인다
- **AND** 에디터 상단 줄 아래에 "태그" 라벨, 그 노트의 태그 칩, 태그 입력창이 있는 태그 줄이 보인다
- **AND** 태그 줄과 원문 사이에 서식 도구 버튼 6종(굵게, 기울임, 제목, 링크, 목록, 코드)이 보인다

#### Scenario: 원문을 고치면 미리보기와 카드가 바뀜
- **WHEN** 사용자가 이틀 전에 마지막으로 고친 노트의 원문 영역에 글자를 입력한다
- **THEN** 미리보기와 해당 노트 카드의 제목·미리보기 문장이 입력 내용을 반영한다
- **AND** 해당 카드의 수정 시각 문구가 "방금 전"으로 바뀐다
- **AND** 사이드바의 노트 개수는 모두 그대로다

#### Scenario: 사이드바 항목은 원문과 선택 노트를 바꾸지 않음
- **WHEN** 사용자가 사이드바의 범위 항목("전체 노트", "폴더 없음", 폴더)을 누른다
- **THEN** 원문과 선택 노트는 바뀌지 않는다. 목록 범위는 `note-folders` capability에 따라 바뀐다

## REMOVED Requirements

### Requirement: 노트 선택과 원문 편집
**Reason**: 서식 도구가 실제로 원문을 바꾸게 되어 "서식 도구와 사이드바 항목은 동작하지 않음" 시나리오가 더는 맞지 않는다. MODIFIED로는 기존 시나리오를 뺄 수 없어 요구사항 이름을 바꿔 다시 정의한다.
**Migration**: 같은 내용은 "노트 열기와 원문 편집" 요구사항이 잇는다. 서식 도구 동작은 `markdown-formatting` capability를 따르고, 사이드바 항목이 원문과 선택 노트를 바꾸지 않는다는 규칙은 "사이드바 항목은 원문과 선택 노트를 바꾸지 않음" 시나리오로 남는다.
