## MODIFIED Requirements

### Requirement: 범위별 빈 상태
목록 범위에 노트가 없을 때 목록 영역은 범위에 맞는 빈 상태를 보여야 한다(SHALL). 검색어가 있어도 이 빈 상태가 검색 결과 없음보다 먼저다(`note-search` capability).

- 노트가 하나도 없고 범위가 "전체 노트" 또는 "폴더 없음": `note-ui-skeleton`의 노트 없음 빈 상태
- 범위가 폴더이고 그 폴더에 노트가 없음: 이 폴더에 노트를 모아 둘 수 있고 새 노트를 만들면 이 폴더에 담긴다는 안내와 "새 노트" 1차 버튼
- 범위가 "폴더 없음"이고 다른 폴더에는 노트가 있음: 모든 노트가 폴더에 정리되어 있다는 안내. "새 노트" 버튼은 보이지 않는다

#### Scenario: 빈 폴더
- **WHEN** 사용자가 노트가 없는 "보관함" 폴더를 고른다
- **THEN** 목록 영역에 보관함에 노트를 모아 둘 수 있다는 문구와 "새 노트" 버튼이 보인다
- **WHEN** 사용자가 그 "새 노트" 버튼을 누른다
- **THEN** 보관함 목록에 "제목 없음" 카드가 selected로 나타나고 원문 영역에 포커스가 있다

#### Scenario: 폴더 없음 노트가 없음
- **WHEN** 모든 노트가 폴더에 들어 있는 상태에서 사용자가 "폴더 없음"을 고른다
- **THEN** 목록 영역에 모든 노트가 폴더에 정리되어 있다는 문구가 보이고 "새 노트" 버튼은 보이지 않는다

#### Scenario: 폴더의 마지막 노트를 옮김
- **WHEN** "보관함"을 보는 중에 보관함의 유일한 노트 A를 열어 폴더를 "개인"으로 바꾼다
- **THEN** 목록 영역에 빈 폴더 상태가 보이고 에디터에는 노트 A가 계속 열려 있다
