# markdown-preview Specification

## Purpose

노트의 마크다운 원문을 입력하는 즉시 안전하게 미리보기로 렌더링하고, 노트 제목과 목록 미리보기 문장을 원문에서 파생해 원문을 노트 내용의 유일한 원본으로 만든다.

## Requirements

### Requirement: 입력 즉시 미리보기 갱신
원문 영역에 입력하면 별도 조작 없이 같은 노트의 미리보기가 현재 원문을 반영해 다시 렌더링되어야 한다(SHALL). 편집한 원문은 같은 세션 안에서 다른 노트로 이동했다 돌아와도 유지되어야 하며(MUST), 저장된 편집은 새로고침한 뒤에도 유지된다. 저장 규칙은 `note-persistence` capability를 따른다.

#### Scenario: 타이핑하면 미리보기가 바뀜
- **WHEN** 사용자가 노트를 열고 원문 끝에 `## 새 섹션`을 입력한다
- **THEN** 미리보기 끝에 "새 섹션" 제목이 h2 스타일로 나타난다

#### Scenario: 다른 노트에 갔다 와도 편집 유지
- **WHEN** 사용자가 노트 A의 원문을 고친 뒤 노트 B를 열었다가 다시 노트 A를 연다
- **THEN** 원문과 미리보기에 고친 내용이 그대로 보인다

#### Scenario: 좁은 폭에서 탭 전환
- **WHEN** 900px 폭에서 사용자가 편집 탭에서 원문을 고친 뒤 미리보기 탭을 누른다
- **THEN** 미리보기에 고친 내용이 반영되어 있다

#### Scenario: 새로고침 후 미리보기
- **WHEN** 사용자가 노트 A의 원문에 `**중요**`를 입력하고 저장 상태가 "저장됨"이 된 뒤 새로고침하고 노트 A를 연다
- **THEN** 미리보기에 "중요"가 굵게 보인다

### Requirement: 지원 마크다운 문법
미리보기는 CommonMark 문법(제목 1~6단계, 문단, 굵게, 기울임, 순서/비순서 목록, 인용, 인라인 코드, 코드 블록, 링크, 구분선)과 GFM 확장 중 표, 취소선, 체크박스 목록, URL 자동 링크를 렌더링해야 한다(SHALL). 렌더링된 모든 요소는 DESIGN.md 토큰으로 정의된 타이포와 색을 사용해야 하며(MUST), 코드와 코드 블록은 모노스페이스 글꼴을 사용해야 한다(MUST).

#### Scenario: 표 렌더링
- **WHEN** 원문에 헤더 행과 구분 행이 있는 GFM 표를 입력한다
- **THEN** 미리보기에 헤더와 본문 행이 구분되는 표가 보이고, 표가 영역보다 넓으면 표 영역 안에서만 가로 스크롤된다

#### Scenario: 취소선과 자동 링크
- **WHEN** 원문에 `~~보류~~`와 `https://example.com`을 입력한다
- **THEN** "보류"는 취소선으로, URL은 링크로 보인다

#### Scenario: 체크박스는 보기 전용
- **WHEN** 원문에 `- [ ] 할 일`과 `- [x] 끝난 일`을 입력한다
- **THEN** 미리보기에 체크되지 않은 체크박스와 체크된 체크박스가 각 항목 앞에 보인다
- **AND** 체크박스를 클릭하거나 키보드로 조작해도 상태와 원문이 바뀌지 않는다

### Requirement: 원문 HTML과 위험한 링크 차단
원문에 쓴 HTML 태그는 해석하지 않고 글자 그대로 보여야 한다(SHALL). 미리보기에 삽입되는 결과에는 스크립트 실행이 가능한 요소, 속성, URL이 포함되지 않아야 한다(MUST NOT).

#### Scenario: HTML 태그는 글자로 보임
- **WHEN** 원문에 `<script>alert(1)</script>`와 `<b>굵게</b>`를 입력한다
- **THEN** 미리보기에 두 문자열이 태그 기호까지 글자 그대로 보이고 스크립트는 실행되지 않는다

#### Scenario: javascript 링크 무력화
- **WHEN** 원문에 `[눌러 보세요](javascript:alert(1))`를 입력하고 미리보기에서 그 부분을 누른다
- **THEN** 스크립트가 실행되지 않는다

### Requirement: 이미지는 불러오지 않고 대체 텍스트로 표시
이미지 문법은 이미지 주소로 요청을 보내지 않아야 하며(MUST NOT), 대신 이미지임을 알리는 대체 텍스트 표시로 렌더링되어야 한다(SHALL). 대체 텍스트가 비어 있으면 이미지라는 사실만 표시한다.

#### Scenario: 외부 이미지
- **WHEN** 원문에 `![구조도](https://example.com/a.png)`를 입력한다
- **THEN** 미리보기에 "이미지: 구조도" 형태의 표시가 보이고, 해당 주소로 네트워크 요청이 발생하지 않는다

#### Scenario: 대체 텍스트 없는 이미지
- **WHEN** 원문에 `![](https://example.com/a.png)`를 입력한다
- **THEN** 미리보기에 "이미지" 표시만 보인다

### Requirement: 미리보기 링크는 새 창에서 열림
미리보기의 링크를 활성화하면 앱 화면을 벗어나지 않고 새 창(탭)에서 열려야 하며(SHALL), 새 창이 앱 창에 접근할 수 없어야 한다(MUST). 링크는 본문 대비 4.5:1 이상을 만족해야 한다(MUST).

#### Scenario: 링크 클릭
- **WHEN** 사용자가 미리보기의 `https://example.com` 링크를 누른다
- **THEN** 링크가 새 탭에서 열리고 노트 앱 화면은 그대로 남는다

### Requirement: 제목과 미리보기 문장 파생
노트의 제목과 목록 카드의 미리보기 문장은 원문에서 파생되어야 한다(SHALL). 원문이 바뀌면 목록 카드, 삭제 확인 문구 등 제목과 미리보기 문장을 쓰는 모든 곳이 즉시 갱신되어야 한다(MUST). 두 값 모두 서식 기호(`**`, `` ` ``, 목록 기호, 링크 주소 등)를 뺀 텍스트이며, 연속 공백은 하나로 줄인다.

- 제목: 원문에 1단계 제목(`# `)이 있으면 첫 1단계 제목의 텍스트다. 없으면 원문의 첫 블록(제목, 문단, 목록 항목, 인용, 코드 블록)에서 비어 있지 않은 첫 줄이다. 원문에 텍스트가 없으면 "제목 없음"이다.
- 미리보기 문장: 제목으로 쓴 줄을 제외하고, 원문 순서상 처음 나오는 텍스트 블록(문단, 목록 항목, 인용 안의 문단)의 텍스트다. 제목과 코드 블록은 건너뛴다. 제목으로 쓴 줄이 여러 줄 문단의 첫 줄이면 같은 문단의 나머지 줄이 미리보기 문장이 된다. 해당하는 텍스트가 없으면 카드에서 미리보기 문장을 표시하지 않는다.

#### Scenario: 제목 바꾸기
- **WHEN** 원문 첫 줄이 `# 3분기 제품 회의록`인 노트에서 사용자가 그 줄을 `# 3분기 회의 정리`로 고친다
- **THEN** 목록의 해당 카드 제목이 "3분기 회의 정리"로 바뀐다
- **AND** 삭제 버튼을 누르면 다이얼로그 문구에 "3분기 회의 정리"가 보인다

#### Scenario: 1단계 제목이 없으면 첫 줄이 제목
- **WHEN** 원문이 빈 줄로 나뉜 두 문단 `**장보기** 목록`과 `토요일에 가기`로 이루어져 있다
- **THEN** 카드 제목은 "장보기 목록", 미리보기 문장은 "토요일에 가기"다

#### Scenario: 여러 줄 문단의 첫 줄이 제목
- **WHEN** 원문이 줄바꿈으로 이어진 한 문단 `장보기 목록`, `우유, 계란, 두부` 다음에 빈 줄과 `토요일에 가기` 문단이 있다
- **THEN** 카드 제목은 "장보기 목록", 미리보기 문장은 "우유, 계란, 두부"다

#### Scenario: 한 줄짜리 문단 하나뿐
- **WHEN** 원문이 `장보기 목록` 한 줄뿐이다
- **THEN** 카드 제목은 "장보기 목록"이고 미리보기 문장은 표시되지 않는다

#### Scenario: 목록으로 시작하는 원문
- **WHEN** 원문이 `- 우유`, `- 계란` 두 항목의 목록뿐이다
- **THEN** 카드 제목은 "우유", 미리보기 문장은 "계란"이다

#### Scenario: 제목과 코드 블록은 미리보기 문장에서 건너뜀
- **WHEN** 원문이 `# 배포 메모`, `## 순서`, 코드 블록, `스테이징 먼저` 문단 순서로 이루어져 있다
- **THEN** 카드 제목은 "배포 메모", 미리보기 문장은 "스테이징 먼저"다

#### Scenario: 원문을 모두 지움
- **WHEN** 사용자가 원문을 모두 지운다
- **THEN** 카드 제목은 "제목 없음"이고 미리보기 문장은 표시되지 않으며, 에디터 미리보기 영역은 비어 있다

#### Scenario: 새 노트의 제목
- **WHEN** 사용자가 새 노트를 만든다
- **THEN** 입력하기 전 카드 제목은 "제목 없음"이고 미리보기 문장은 표시되지 않는다

#### Scenario: 첫 문단 수정
- **WHEN** 사용자가 `# ` 제목 아래 첫 문단에 `**중요**` 표시를 넣는다
- **THEN** 카드 미리보기 문장에 `**` 기호 없이 "중요"가 포함된 문장이 보인다
